# 项目说明

## 项目定位

母婴商城管理系统是一个 Java Web 全栈项目，覆盖商城业务中的商品展示、用户下单、订单管理、内容资讯、评价收藏和后台管理等流程。

## 适合展示的能力点

- 能够基于 Spring Boot 搭建后端服务
- 能够使用 MyBatis-Plus 完成数据库访问和分页查询
- 能够设计并维护多模块业务表结构
- 能够完成 Vue 管理端与后端接口联调
- 能够整理项目文档、运行步骤和演示数据

## 面试介绍话术

可以这样介绍：

> 这是一个母婴商城方向的全栈项目，我主要关注后端业务接口、数据库表结构、后台管理模块和前后端联调。项目包含商品、分类、购物车、订单、评价、收藏、地址、资讯和客服等模块。后端使用 Spring Boot + MyBatis-Plus，数据库使用 MySQL，后台管理端使用 Vue2 + Element UI。为了方便展示，我整理了数据库脚本和运行文档，并清理了构建产物和本地配置。
